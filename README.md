# Custo Certo

Projeto em Next.js para organizar compras da casa, comparar preços, acompanhar orçamento e criar alertas.

## Rodar no computador

```bash
npm install
npm run dev
```

Depois abra:

```text
http://localhost:3000
```

## Publicar

Importe este repositório na Vercel e clique em Deploy.

## Importante

Não use junto com os arquivos antigos:

- index.html
- styles.css
- app.js
