# Custo Certo

Versão visual inicial, moderna e responsiva.

## Publicar no GitHub Pages

1. Extraia o ZIP.
2. Envie `index.html`, `styles.css`, `app.js` e `README.md` para a raiz do repositório.
3. No GitHub, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/(root)`.
6. Clique em **Save**.

A primeira versão inclui painel, produtos, comparação, orçamento, alertas, busca e cadastro de produtos.
